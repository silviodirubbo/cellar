{% comment %} Live availability for one upcoming tasting on the schedule card, from _data/availability.yml (written by the calendar sync, see tools/calendar-sync/README.md). Param: tasting (an entry of _data/tastings.yml). Renders "N places available" ("1 place available" for exactly 1), or "Fully booked" when no places are left. Renders nothing for a past tasting or one with no entry. Capacity comes from the tasting's own `capacity` field, default 6. Display override: a tasting with `force_fully_booked: true` in _data/tastings.yml shows "Fully booked" (avail_left 0) whatever its entry says. Display only: availability.yml keeps the real count and the calendar sync keeps updating it. Like every count, it stops showing once the tasting is past, and the daily status sync deletes the line then. Also sets, for the caller (Jekyll includes share the page's variables): avail_left places left, or nil when nothing is shown avail_capacity the tasting's capacity The sign-up dialog reads both from the "I'm coming" button's data attributes and shows "N places available out of C" (assets/js/forms.js). {% endcomment %} {% assign avail_left = nil %} {% assign avail_entry = site.data.availability[include.tasting.slug] %} {% assign avail_today = site.time | date: "%Y-%m-%d" %} {% assign avail_date = include.tasting.date | date: "%Y-%m-%d" %} {% assign avail_past = false %} {% if include.tasting.status == "past" %}{% assign avail_past = true %}{% endif %} {% if include.tasting.date and avail_date < avail_today %}{% assign avail_past = true %}{% endif %} {% assign avail_capacity = include.tasting.capacity | default: 6 %} {% assign avail_show = false %} {% if avail_entry %}{% assign avail_show = true %}{% endif %} {% if include.tasting.force_fully_booked == true %}{% assign avail_show = true %}{% endif %} {% if avail_past %}{% assign avail_show = false %}{% endif %} {% if avail_show %} {% assign avail_taken = avail_entry.taken | default: 0 | at_least: 0 %} {% assign avail_left = avail_capacity | minus: avail_taken | at_least: 0 %} {% if include.tasting.force_fully_booked == true %}{% assign avail_left = 0 %}{% endif %} {%- if avail_left == 0 -%} Fully booked {%- elsif avail_left == 1 -%} 1 place available {%- else -%} {{ avail_left }} places available {%- endif -%} {% endif %}
